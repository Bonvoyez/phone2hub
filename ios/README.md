# Phone2Hub - iOS Client

Client directory dedicated to iOS (iPhone / iPad). Developed using Xcode on macOS.

## Roles & Responsibilities
* Ultra-lightweight camera capture (4K / 60fps) and audio capture (`AVFoundation`)
* Hardware-accelerated H.264 / AAC encoding (`VideoToolbox`)
* High-speed packet transmission over USB cable (`usbmuxd` local port binding)
